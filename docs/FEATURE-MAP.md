# Mapa funkcji — która aplikacja

Jeśli wątpliwość: nie implementuj. Dopisz wiersz tutaj.

## Młoda Wataha — USER (dziecko)

- logowanie USER (Wejdź do Młodej Watahy)
- Młody WILK
- Nauka, moje lekcje, quizy diagnostyczne, powtórki
- Nora Młodego Wilka
- Lizaki Watahy, zdobyte nagrody
- profil dziecka
- sparowany rodzic / opiekun
- własne zgłoszenia (piosenka, nagroda, specjalne)
- tryb kryzysowy dziecka, SOS dziecka
- własne materiały i nagrody

## Młoda Wataha — ADMIN (Wojan, dorosły)

- osobne wejście Panel administratora
- treści edukacyjne, etapy, przedmioty, poziomy / klasy
- quizy, nagrody, Lizaki, katalog Nory, koszty nagród
- zgłoszenia specjalne i piosenek, statusy produkcji (podgląd)
- materiały do rodzica, zatwierdzone zgłoszenia Family Bridge
- konfiguracja Młodego WILKA, baza wiedzy, sync, powiadomienia systemowe
- ustawienia aplikacji, użytkownicy w zakresie admin, podgląd systemu
- włączanie / wyłączanie funkcji z backendu

## Polska Wataha — dorosły

Już jest i zostaje:

- start, tryb kryzysowy, SOS, mapa, sieć (mesh / BT / Wi-Fi Direct / LoRa)
- WILK dorosły, barter, wiadomości, powiadomienia, profil
- Radio watahy, Wojan Live Radio (odbiornik)
- PWA Android / iOS

Dopisać później, dorosłym UI, bez dziecięcych ekranów:

- Dodaj Młodego Wilka
- kod parowania
- lista powiązanych dzieci
- zgody rodzica
- zatwierdzanie próśb dziecka
- odbiór materiałów
- zatwierdzanie przekazania nagrody / utworu do Wojan Studio

## Wojan Studio

- źródło i administracja live / muzyki
- produkcja utworów
- przyjmowanie tylko zatwierdzonych zgłoszeń z Family Bridge
- nie jest logowaniem dziecka

## Family Bridge (backend)

- tożsamość i role
- relacja rodzic — dziecko
- zgody, kolejki próśb, powiadomienia między aplikacjami
- backend nagród w zakresie przekazań między aplikacjami
- sync statusów

Nie ma własnego ekranu głównego dla użytkownika.

## Świadomie poza tą mapą

Nie przenosić do Młodej Watahy: mesh taktyczny, LoRa USB, barter sąsiedzki, radio kanałów watahy, mapa SOS dorosłych.
Nie przenosić do Polskiej Watahy: lekcji, Nory, Lizaków dziecka, Młodego WILKA.
